فاشن لاين - نسخة المتجر مع المقاسات والألوان والمخزون

الميزات الجديدة:
- كل منتج فيه مقاسات XS / S / M / L / XL / XXL.
- ألوان: أسود / أبيض / رمادي / بيج.
- مخزون منفصل لكل لون + مقاس.
- إذا كانت الكمية 0 يظهر الخيار غير متوفر ولا يمكن إضافته للسلة.
- لوحة التحكم admin.html تسمح بتغيير كمية كل لون ومقاس مباشرة.
- السلة تحفظ اللون والمقاس لكل قطعة.

مهم:
هذه النسخة تعتمد على localStorage، لذلك تغييرات لوحة التحكم محفوظة على نفس المتصفح/الجهاز فقط. لكي تكون لوحة التحكم حقيقية وتتحكم بالمخزون لجميع العملاء على موقعك المنشور، نحتاج ربطها بقاعدة بيانات/Backend (مثلاً Cloudflare D1 + Workers) وحماية لوحة الإدارة بكلمة مرور.
